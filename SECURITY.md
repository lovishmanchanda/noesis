# Security policy

NOESIS is designed so that user data never leaves the user's computer. Please report anything that could break that promise, or any other security problem, privately.

To report a problem, use the repository's private vulnerability reporting (Security tab, "Report a vulnerability"). Please do not open a public issue for security problems.

Include what you found, the steps to reproduce it, and the browser, operating system and version involved. You will get a reply as soon as the maintainer can.

## Scope

- The web application and its handling of files, local storage and the engine.
- The optional local companion program: its pairing, origin checks and file handling (see `docs/design/companion.md`).
- The build and release configuration.
