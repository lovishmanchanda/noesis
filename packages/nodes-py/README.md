# nodes-py

Plain pandas and scikit-learn functions, one per pipeline step. The in-browser engine (Pyodide) and the local companion run this same code, so results match and exported scripts are what actually ran.

## What is here

| Module | Contents |
|---|---|
| `registry.py` | Reads the shared parameter registry (`packages/registry/data/registry.json`) and resolves each step's effective settings: the given value, else the default; settings that do not apply are left out |
| `context.py` | `Data` (frames before and after the split), `Ctx` (task, roles, seed, fitted transformers, event and cancel hooks) |
| `steps_data.py` | load, drop columns, drop duplicates, filter rows, split (random, stratified, group, time, none) |
| `steps_prepare.py` | impute, outliers, encode, scale, derive a feature, select features, reduce dimensions |
| `runner.py` | Runs a pipeline in dependency order and reports events |

Steps that learn from data fit on the training rows only and raise `LeakageError` if the split has not happened. The fitted transformers are kept in `ctx.fitted` so they can be applied to new rows later.

## Running the tests

```bash
python -m pip install -r packages/nodes-py/requirements-dev.txt
python -m pytest packages/nodes-py
```

The pinned versions match the browser engine (Pyodide 314.0.7). Test data is generated by `fixtures/data/generate.py`.
